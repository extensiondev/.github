# extension.dev

Build, preview, release and submit browser extensions to every store.

Extension.js is the framework you run. extension.dev is where it ships.

- **MCP server** for AI agents: `npx @extension.dev/mcp` ([repo](https://github.com/extensiondev/mcp))
- **Agent skill**: `npx skills add extensiondev/skill` ([repo](https://github.com/extensiondev/skill))
- **Docs**: [docs.extension.dev](https://docs.extension.dev)
- **Templates**: [templates.extension.dev](https://templates.extension.dev)
